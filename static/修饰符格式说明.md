# ST.26 序列修饰符格式快速参考

## 🎯 两种支持格式

系统支持以下 **两种严格格式**，请选择其中一种填写：

### 格式对比

| 对比项 | 格式 1（旧格式） | 格式 2（新格式） |
|--------|----------------|-----------------|
| **命名** | 旧格式 | 新格式 |
| **特点** | 修饰符直接写在碱基前 | 使用括号结构 |
| **硫代表示** | `s` 在碱基间 | `*` 在组间 |
| **示例** | `mGmGmUmUfGmGfA` | `(VP)(mG)*(mG)*(mU)(mU)(fG)(mG)(fA)(mU)(fU)(fU)(fU)(mU)(fC)(mU)(mU)(mG)(mC)(mU)(mA)(mU)(mG)(L96)` |
| **推荐** | ⭐ **推荐使用** | 可用（会被自动转换） |

## 📝 完整示例

### 示例 1：格式 1（推荐）
```
mGmGmUmUfGmGfAmUfUfUfUmUfCmUmUmGmCmUmAmUmG
```
- `mG` = G 碱基的 2'-O-甲基化
- `fG` = G 碱基的 2'-氟代
- `AsG` = A 和 G 之间是硫代磷酸酯键

### 示例 2：格式 2（括号格式）
```
(VP)(mG)*(mG)*(mU)(mU)(fG)(mG)(fA)(mU)(fU)(fU)(fU)(mU)(fC)(mU)(mU)(mG)(mC)(mU)(mA)(mU)(mG)(L96)
```
- `(VP)` = 5'端乙烯基膦酸酯
- `(mG)` = G 碱基有甲基化修饰
- `*(mG)` = G 碱基后跟硫代磷酸酯（`*` = 硫代键）
- `(L96)` = L96 配体（会被自动移除）

### ❌ 不支持的格式
```
❌ CmsUfsAmCmUmCf  ← 修饰符在碱基后面（格式不支持）
❌ GmUmAfGfCmGmGfA  ← 混合格式
❌ mGAmCfsGmUfAfb   ← 修饰符在后
```

## ⚡ 快速规则

1. **位置规则**：
   - 格式 1：修饰符 **在碱基前面** (`mG`)
   - 格式 2：使用 **括号结构** (`(mG)*(mU)`)
   - ❌ **不支持修饰符在碱基后面**（如 `Cm`、`Um`、`Af`）

2. **硫代修饰** (`s` / `*`)：
   - 格式 1：`s` 在两个碱基之间 `AsG`
   - 格式 2：`*` 在组之间 `(mG)*(mU)`
   - 两者含义相同（硫代磷酸酯键）

3. **端基修饰**：
   - `p` (5'端) 通常在开头
   - `b` (3'端生物素) 通常在结尾

4. **特殊标记**：
   - `(VP)` = 5'端乙烯基膦酸酯
   - `*` = **硫代磷酸酯键**（不是分隔符）
   - `(L96)` 或 `-L96` = L96配体（会被移除）

5. **格式限制**：
   - ❌ **两种格式不能混合使用**
   - ✅ 系统会将格式 2 自动转换为格式 1
   - ✅ 推荐使用格式 1

## 💡 使用建议

| 场景 | 推荐格式 | 原因 |
|------|---------|------|
| 新数据录入 | 格式 1 | 符合文献惯例 |
| 已有数据 | 保持原格式 | 避免转换错误 |
| 数据库导入 | 按数据库格式 | 与原始数据一致 |
| 文献复制 | 格式 1 | 文献常用格式 |

## 🔍 格式识别示例

| 输入序列 | 识别格式 | 处理结果 |
|---------|---------|---------|
| `mGmA` | 格式 1 | G、A 甲基化 |
| `(mG)*(mA)` | 格式 2 | G、A 甲基化 + 硫代 |
| `mGAsA` | 格式 1 | G、A 甲基化，硫代键 |
| `(VP)(mG)*(mU)(L96)` | 格式 2 | VP端基，G、U甲基化，硫代键 |
| `AsGfsC` | 格式 1 | A-G硫代，G-C氟代硫代 |

## ✅ 验证清单

使用前确认：

- [ ] 选择一种格式（格式 1 或格式 2）
- [ ] 不混用两种格式
- [ ] 硫代修饰位置正确（格式1用`s`，格式2用`*`）
- [ ] 端基修饰位置正确
- [ ] 特殊标记格式正确
- [ ] 序列中无空格
- [ ] 分子类型已指定
